Trabalho prático de Programação Web - Cliente (ISLA Gaia).

## Grupo
- Matheus Palmeira Dantas

## Tema
NortePet — serviço fictício de pet sitting e visitas ao domicílio para animais de companhia em Vila Nova de Gaia.

## Público-alvo
Pessoas de Vila Nova de Gaia que precisam de apoio temporário para cuidar dos seus animais, por exemplo durante o trabalho ou uma viagem.

## Objetivo
Apresentar o serviço, explicar as opções de acompanhamento e permitir que potenciais clientes encontrem os contactos.

## Framework CSS — Entrega 6

Framework escolhida: Bootstrap
Versão: 5.3.9

### Justificação

Escolhemos o Bootstrap porque permite criar
interfaces responsivas de forma simples.

A framework disponibiliza componentes
reutilizáveis e uma grelha responsiva,
facilitando a adaptação do NortePet
a telemóveis, tablets e computadores.

Mantivemos o ficheiro estilos.css para
personalizar o aspeto do site sem alterar
o código original do Bootstrap.

### Integração

O Bootstrap é carregado através de CDN.
O projeto utiliza apenas esta framework CSS.

Documentação:
https://getbootstrap.com/docs/5.3/
