# NortePet

Trabalho prático de Programação Web - Cliente (ISLA Gaia).

## Grupo
- Matheus Palmeira Dantas
- Duarte da Silva
- António Francisco Santos

## Tema
NortePet — serviço fictício de pet sitting e visitas ao domicílio para animais de companhia em Vila Nova de Gaia.

## Público-alvo
Pessoas de Vila Nova de Gaia que precisam de apoio temporário para cuidar dos seus animais, por exemplo durante o trabalho ou uma viagem.

## Objetivo
Apresentar o serviço, explicar as opções de acompanhamento e permitir que potenciais clientes encontrem os contactos.
