# E5 — Testes de design responsivo

Esta pasta contém as capturas de ecrã
que documentam a adaptação do NortePet
a diferentes tamanhos de ecrã.

## Resoluções testadas
- 360 px — Telemóvel
- 1280 px — Computador

## Páginas documentadas
- Página inicial
- Página de serviços

## Verificações
- Navegação adaptada ao ecrã
- Grelha CSS Grid responsiva
- Imagens ajustadas à largura disponível
- Ausência de deslocação horizontal
