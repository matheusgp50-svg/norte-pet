
# Guia de Estilo — NortePet

## 1. Introdução

O NortePet é um website dedicado aos cuidados e
serviços para animais de estimação.

Este guia define a identidade visual do website,
garantindo consistência entre todas as páginas.

## 2. Paleta de cores

| Cor | Código HEX | Utilização |
|---|---|---|
| Verde primário | #176B5B | Cabeçalho e botões |
| Verde secundário | #14532D | Navegação e rodapé |
| Laranja escuro | #A65300 | Destaques e foco |
| Branco | #FFFFFF | Fundo principal |
| Cinzento claro | #F1F5F4 | Formulários e tabelas |
| Cinzento escuro | #1F2937 | Texto principal |
| Cinzento médio | #CBD5D1 | Bordas e separadores |

## 3. Tipografia

Família principal:
Arial, Helvetica, sans-serif.

- Texto normal: 16px.
- Título H1: 32px.
- Título H2: 24px.
- Espaçamento entre linhas: 1.6.
- Títulos destacados através de cor e tamanho.

## 4. Contraste e acessibilidade

O objetivo é cumprir as WCAG 2.2, nível AA.

Requisitos:
- Texto normal: contraste mínimo de 4,5:1.
- Texto grande: contraste mínimo de 3:1.

### Rácios de contraste

| Texto | Fundo | Rácio |
|---|---|---|
| #FFFFFF | #176B5B | 6,42:1 |
| #FFFFFF | #14532D | 9,55:1 |
| #1F2937 | #FFFFFF | 14,68:1 |
| #1F2937 | #F1F5F4 | 13,34:1 |
| #14532D | #FFFFFF | 9,55:1 |
| #A65300 | #FFFFFF | 4,89:1 |

Todos estes pares cumprem o contraste
mínimo de 4,5:1 para texto normal.

## 5. Organização do CSS

O ficheiro estilos.css contém regras
organizadas e comentadas por secções:

- Cores e tipografia
- Estilos gerais
- Cabeçalho
- Navegação
- Conteúdo principal
- Títulos
- Parágrafos
- Secções
- Imagens
- Ligações
- Listas
- Tabelas
- Formulários
- Botões
- Rodapé
- Acessibilidade

## 6. Consistência visual

Todas as páginas HTML utilizam a mesma
folha de estilos externa, estilos.css.

A utilização de variáveis CSS permite
manter as cores consistentes e facilita
alterações futuras ao website.
